# WiFi CSI Sensing Research

This project explores how WiFi Channel State Information can detect motion and environmental changes for physical security intelligence.

## Core Pipeline

1. Edge Processing Layer
2. Temporal Analysis Layer
3. Intelligence Layer

## Current Phase

Layer: Edge Processing Layer

Current goal: Build the repository foundation for reproducible CSI collection, processing, and experiment logging.

## Research Constraints

- Small, testable iterations
- Controlled environments only
- Honest documentation of false positives
- Evidence-backed conclusions
- Physical security relevance required
